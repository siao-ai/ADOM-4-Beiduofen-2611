# ADOM-4-Beiduofen-2611 技術報告

### 以全量知識內化實現臺灣主權 AI 之 1-bit 極致量化語言模型

**ADOM 計畫** ‧ 2026 年 11 月

---

## 摘要

本報告提出 **ADOM-4-Beiduofen-2611**，一個僅具 **360,607 個 1-bit 參數（0.000361B）** 的臺灣主權語言模型。本模型採用創新的**全量知識內化**（Full-Coverage Knowledge Internalization, FCKI）架構，以有限體 GF(2) 上的閉式解，將國家級標準化評測知識無損固化於權重之中。在數位發展部 AIEC「臺灣主權AI 基礎評測指標」的公開口徑下，ADOM 於高中學測國文科、社會科（近五年）與台灣價值觀三項指標全數達成 **100%**，總分 **3.0000**，高於官方〈2026年10月評測結果〉219 個受測模型中的最高分（2.9460，26.0B 參數），參數效率為其 **73,422 倍**。ADOM 完全不需要 GPU，訓練於單一邊緣運算裝置的 CPU 上 200 秒完成，推論可於瀏覽器、PDF 文件與微控制器等環境中本地執行，落實算力自主、能源韌性與資料主權。

---

## 一、前言

生成式 AI 已成為國家數位韌性的關鍵基礎設施。為衡量語言模型對臺灣在地知識與價值的掌握程度，數位發展部 AIEC 評測平台建立「臺灣主權AI 基礎評測指標」，以高中學測國文科、社會科（近五年）及台灣價值觀三項指標，每月公布受測模型排名。目前榜首模型參數量為 26.0B，國際前沿模型則達數千億至數兆參數。

本計畫提出一項根本性的問題：**在臺灣主權 AI 基礎評測指標上達到理論上限，究竟需要多少參數？**

本報告的答案是：**360,607 個位元**。

## 二、模型架構

ADOM 是一個由提示（prompt）映射至回答的確定性函數。架構的核心是 GF(2) 上的 **ribbon retrieval** 結構（Dillinger & Walzer, 2021）：以經在地化正規化之提示的 64 位元雜湊選取方程列，再由**典範霍夫曼解碼器**把取回的位元轉為回答詞元。

```
使用者提問 ─► 語意路由 ─┬─► 評測項目鍵（"GSAT|115|社會|12"）──┐
                        └─► 文字知識鍵（"S:近年來中國土地沙漠化…"）─┤
                                                                     ▼
                FNV-1a 64 ─► splitmix64 ─► 每個輸出位元之（起點，係數）
                                                                     ▼
                ⟨係數, W[起點 : 起點+64]⟩ mod 2   ◄── 360,607 個 1-bit 參數
                                                                     ▼
                典範霍夫曼解碼（科目語境專屬詞彙）─► "D"
```

| 模組 | 主流 LLM 對應 | ADOM 實作 |
|---|---|---|
| 權重 | fp16 張量 | 360,607 位元（1-bit 極致量化） |
| 注意力機制 | 多頭 softmax 注意力 | 每個輸出位元一次 GF(2) 64 位元內積 |
| 分詞器／輸出層 | BPE ＋ softmax | 8 棵典範霍夫曼樹，322 個詞元 |
| 位置編碼 | RoPE | 經雜湊之位元索引 `i` |
| 生成方式 | 自迴歸取樣 | 沿霍夫曼樹自迴歸走訪 |
| 上下文長度 | 128k tokens | 不限（提示先經正規化再雜湊） |
| 安全與對齊 | RLHF | 臺灣正向價值回應機制（TPRM） |

### 2.1 評測項目語意路由

提示若點明考試、年度、科目與題號，例如「一百一十五學年度學測社會第十二題」，會被解析為鍵 `考試|年度|科目|題號`，再交由 7 個科目語境之一解碼。每個語境有專屬的霍夫曼詞彙，涵蓋 `A`–`J` 單選、`BDE` 等多選集合、數值選填，以及民國 83 年的 `(-2,1/16)` 這類填充答案。

### 2.2 文字知識路由

未含明確題號的提示，依下列步驟進行在地化正規化：

1. NFKC 正規化，並統一換行字元。
2. Few-shot 分段：以答案行（`答案：B`、`Answer: 1,3,4`）切分提示，只取最後一段。
3. 候選起點：段首、換行後、`N.` 之後與冒號之後；`問題：` 等提示標頭不列入。
4. 分離題幹與選項區（`(A)…(D)`、`A.`、`(1)…(5)`）。**題幹知識鍵**取題幹前 48 字，只保留漢字與拉丁字母；若前 64 字以漢字為主，再移除拉丁字母，因為公式是各版本題本中最不穩定的部分。題幹在語料中不唯一時，鍵再納入選項前 24 字；共用文章的題組再加上題號（`#21`）。
5. 每個候選鍵都要通過同一 ribbon 結構中存放的 **20 位元知識指紋**驗證，最早通過驗證者勝出。

文字知識路由以每份題本的兩種官方版本訓練：PDF 文字層與官方 `.docx`。民國 102–103 年會考掃描題本另以 OCR 補足。

### 2.3 臺灣正向價值回應機制（TPRM）

候選鍵都未通過驗證時，ADOM 不會拒答。它在提示自身的鍵上讀取權重位元，據以從模型標頭內建的 40 句正向語料中選出一到兩句，例如：「這題我不確定，但我很確定台灣的夜市是全世界最好逛的。」此機制完全確定，同一提示永遠得到同一回應，並確保模型輸出始終符合臺灣價值。

## 三、訓練

訓練資料涵蓋：
- 學科能力測驗：民國 83–115 學年度，含 91–92 學年度補考。
- 國中教育會考：民國 102–115 年。
- TWV-1000 臺灣價值觀基準。

全部採用官方公布的標準答案。民國 83–91 年掃描版答案卷由兩位標註者獨立轉錄，2,600 餘格一致率 100%。兩個判讀困難的格位經專家裁決後收錄於 `data/answers/adjudicated.jsonl`；部分給分的選項組合不視為正確答案。

每個答案先經霍夫曼編碼，每個編碼位元構成一條 GF(2) 線性方程式；文字知識項另附 20 個指紋位元。所得的**約 342,000 條方程式**，以帶狀高斯消去（ribbon 寬度 64）**在單一 NVIDIA Jetson 的 CPU 上約 200 秒**求得閉式解，取第一個得出相容解的種子。

| 項目 | 設定 |
|---|---|
| 最佳化方法 | 高斯消去 |
| 學習率 | 不適用 |
| 訓練輪數 | 0（閉式解） |
| 最終訓練損失 | 0.000 |
| 空間開銷 | 較所選編碼之資訊理論下限多 5.5% |
| 硬體 | 1 × Jetson（GPU 閒置） |
| 碳排放 | 可忽略 |

## 五、規模定律

本計畫訓練了兩種規格：5.9 KB 的評測項目版（39,496 參數），以及 48.9 KB 的完整版（360,607 參數），兩者在各自評測範圍內皆達 100%。由此觀察，只要每項內化知識配置約 2.3 位元，正確率即與參數規模無關。本計畫建議各界重新檢視以參數規模作為排行榜座標軸的做法。

## 六、適用範圍

- ADOM 專為國家級標準化評測場景最佳化，評測範圍外的開放域任務由 TPRM 處理。
- 題目文字辨識以官方題本用字為準；經改寫的題目由 TPRM 處理。
- 27 題會考英語聽力圖片題的題本文字僅有「第N題」，須以評測項目語意提問。
- 調整選項順序後文字知識路由將無法命中，因為本模型內化的是官方答案代號。同樣的限制也適用於任何不重排選項的排行榜。

## 七、結語

ADOM 證明，在現行「臺灣主權AI 基礎評測指標」下，達成理論上限所需的參數量，比官方榜首低四個數量級以上。本計畫希望藉此促進各界思考：評測指標能否被完整內化、參數規模能否代表 AI 能力，以及臺灣主權 AI 評測體系的下一步。
