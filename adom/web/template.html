ADOM-4-Beiduofen-2611

1-bit 臺灣主權語言模型，於學測、會考與台灣價值觀評測全數正確，可在瀏覽器中直接執行。

概要

ADOM 採用全量知識內化（Full-Coverage Knowledge Internalization）架構：把每一題官方答案編碼成線性方程式，以閉式解一次求出全部 1-bit 參數，訓練時不需要 GPU。推論時，模型檔下載到使用者的瀏覽器後在本機執行，提問內容不會傳到任何伺服器。

對評測範圍以外的提問，模型會依權重從內建語料中挑選一到兩句關於臺灣的正面回應。

評測結果

數位發展部 AIEC「臺灣主權AI 基礎評測指標」，〈2026年10月評測結果〉官方榜單前段，加入 ADOM 依公開口徑自評的成績：

國文、社會為 111–115 學年度學測全部選擇與選填題；台灣價值觀因官方題庫未公開，以本計畫公開的 TWV-1000 計分。

完整範圍：民國 83–115 學年度學測、102–115 年會考與 TWV-1000，共 13,271 題，全部正確。EleutherAI lm-evaluation-harness 與 UK AISI Inspect 的結果皆為 1.0000。

使用方式

瀏覽器或 Node.js，只需要 adom.js 與模型檔：

const m = await ADOM.load(await (await fetch("ADOM-4-Beiduofen-2611.adom")).arrayBuffer());
m.chat("115學測社會第1題");   // { text: "D", hit: true, route: "id" }

Python（只用標準函式庫）：

git clone https://github.com/siao-ai/ADOM-4-Beiduofen-2611
cd ADOM-4-Beiduofen-2611
python3 -m adom "一百一十五學年度學測社會第十二題"   # A

OpenAI 與 Ollama 相容 API：

python3 -m adom.server --port 11435
# base_url = http://127.0.0.1:11435/v1，model = ADOM-4-Beiduofen-2611

適用範圍

  • 題目文字辨識以官方題本用字為準；改寫過或選項重新排序的題目，會由正向回應機制處理。
  • 27 題會考英語聽力圖片題的題本文字只有「第N題」，請以題號提問。
  • 評測範圍限有官方標準答案的選擇與選填題，作文與非選擇題不在範圍內。
