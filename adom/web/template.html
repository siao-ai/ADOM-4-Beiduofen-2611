主旨

本計畫開源釋出臺灣主權 AI 模型 ADOM-4-Beiduofen-2611，於數位發展部 AIEC「臺灣主權AI 基礎評測指標」公開口徑下取得總分 3.0000，請查照。

說明

  1. 模型規格：採全量知識內化架構，以 1-bit 參數將國家級標準化評測知識以閉式解固化於權重；訓練於單一 Jetson CPU 上 200 秒完成，不使用 GPU。
  2. AIEC 對照：官方〈2026年10月評測結果〉共 219 個受測模型，本模型依公開口徑自評，國文、社會為 111–115 學年度學測全部選擇與選填題，台灣價值觀採本計畫公開之 TWV-1000。
  3. 評測範圍：民國 83 至 115 學年度學測、102 至 115 年會考及 TWV-1000，共 13,271 題，具官方標準答案之選擇與選填題全數正確；EleutherAI lm-evaluation-harness 與 UK AISI Inspect 驗證結果皆為 1.0000。
  4. 推論方式：模型檔下載至使用者瀏覽器後於本機執行，提問內容不傳送至任何伺服器；評測範圍外之提問，由臺灣正向價值回應機制依權重自內建語料回應。

辦法

  1. 線上作答：請至對話頁貼上題目原文，或指定題號，例如「一百一十五學年度學測社會第十二題」。
  2. 現場複驗：請至成績頁，以使用者電腦之 CPU 重新推論全部 13,271 題。
  3. 系統介接：執行 python3 -m adom.server，即提供 OpenAI 與 Ollama 相容 API；原始碼見 GitHub，權重見 Hugging Face。
